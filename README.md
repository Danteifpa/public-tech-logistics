# 🏛️ PublicTech Logistics Manager
**Sistema Inteligente de Gestão de Ativos e Suporte Externo**

O **PublicTech Logistics** é uma solução Full-Stack desenvolvida para modernizar o controle de inventário e o atendimento técnico em organizações e órgãos públicos. O sistema integra hardware e software para oferecer transparência e agilidade na gestão de logística técnica.

### 🚀 Funcionalidades Chave
* **Rastreamento via QR Code:** Consulta instantânea de especificações e histórico de ativos em campo.
* **Módulo de Atendimento Externo:** Registro de chamados fora da sede com emissão de relatórios automatizados (PDF).
* **Agenda Integrada:** Calendário dinâmico para controle de eventos, reuniões e prazos de devolução.
* **Segurança Granular:** Implementação de Row Level Security (RLS) para diferentes níveis de acesso (Admin, Técnico e Estagiário).

### 🛠️ Tecnologias Utilizadas
* **Frontend:** Next.js 14, TypeScript, Tailwind CSS, Shadcn/UI.
* **Backend & Database:** Supabase (PostgreSQL), Edge Functions.
* **Relatórios:** Automação de PDFs profissionais para documentação de campo.
